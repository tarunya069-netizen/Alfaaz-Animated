# Alfaaz — Unspoken

A mobile-first, cinematic animated story about love, roses, memories, and quiet regret. Original text and animation; not an official music video.

## Features
- Animated falling rose petals and dreamy midnight sky
- Scroll-through emotional chapters
- Optional local audio file picker (audio stays on the visitor's device; no copyrighted audio is included)
- Reduced-motion support and responsive layout

## Run
Open `index.html` in any browser, or enable GitHub Pages in **Settings → Pages → Deploy from a branch → main / root**.
